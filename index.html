Project 01 — AI · Career Tech

AI Career Recommendation System

An AI-powered engine that takes a student's interests, strengths, and vague sense of direction and turns them into actual career paths — not a five-question quiz result.

Built around student profiling: normalizing input signals and weighing stated interests against demonstrated strengths before generating a recommendation, so two students with similar answers don't get identical output.

Output isn't just a job title — it maps a learning pathway, so the recommendation comes with a next step attached.

Project 02 — Music · AI

DriftTune

A full-stack AI music recommendation platform analyzing 413,000+ tracks in real time, built on a FastAPI backend with Pandas handling the heavy data work underneath.

The recommendation core runs on vector similarity, layered with mood analysis, genre weighting, and artist-diversity filtering — so it doesn't just loop the same five artists back at you.

On the frontend: adaptive themes, a custom particle engine, interactive radar charts for visualizing a track's mood profile, a custom cursor, and early groundwork for streaming integrations.

This is the project where DJing stopped being a hobby and started being an input — pacing and track-selection instincts translated almost directly into the recommendation logic.

Project 03 — Systems · Fintech

NexBank

A dual-platform banking system — a WebGL-powered web app and a Java Swing desktop client — sharing one underlying architecture instead of being built as two disconnected products.

Focused on staying lightweight: object-oriented design, GPU-accelerated rendering, custom UI components, and a zero-dependency approach wherever possible.

Stress-tested through thousands of concurrent simulated transactions without losing data integrity — reliability treated as a feature, not an afterthought.
